# Known limitations

- This is an unofficial engineering extension of the original MutaBind2 method, with unchanged pretrained models. Speed improvements do not establish higher biological prediction accuracy.
- The general GPU scan workflow is validated for independent single substitutions. The legacy multiple-mutation interface is retained; combination-mutation GPU support has not been validated.
- The current structure interface supports a single-model protein PDB, standard amino acids and alphanumeric chain IDs. Missing coordinates are not rebuilt. mmCIF, nucleic acids, ligands and arbitrary nonstandard residues are outside this interface's validated scope.
- GPU kernels support checked subsets of the CHARMM PB calculation. Unsupported conditions explicitly fall back to the CPU. CUDA runtime failures abort. A CUDA architecture/toolchain change requires validation on that installation.
- CHARMM native builds are tied to a checksum-verified CHARMM 51 baseline. This is not a drop-in patch for arbitrary future CHARMM releases. Large systems can still exceed host/GPU memory limits.
- Default PROVEAN scoring uses each continuous observed structure fragment. A short or truncated fragment can select different homologs and produce a different score from the full protein. Prefer a verified complete sequence when available; all PDB/FASTA positions must agree.
- **PROVEAN no-homolog handling:** the native program can use the query itself as the only supporting sequence. The adapter currently accepts finite scores from this path. Native logs state `use the query itself as a supporting sequence`, but the final table lacks a dedicated quality flag. Such scores lack homolog-based conservation evidence; inspect the supporting-sequence count and native log.
- **PROVEAN cache identity:** complete-sequence cache reuse checks the query and mutation set before reading the requested tool/database configuration. Reusing the same cache directory after changing a database or tool version can return an old score. Use a new cache and scan output directory after any such change. Database/tool fingerprints should be included in a future cache revision.
- The historical local NR snapshot contains 182,860,753 sequences, but its original NR release date is unknown. The NR database is not distributed here. Different database releases and homolog selections can change PROVEAN scores, including their interpretation near a cutoff.
- PROVEAN is a sequence-variation feature, not a binding free energy. A functionally damaging classification does not directly establish weakened protein–protein binding.
- Native executables, configuration files, model files, build directories and checkpoints are trusted installation inputs. This local CLI is not a sandbox for running untrusted binaries or for hosting arbitrary users' jobs.
